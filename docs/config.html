config.json を画面から作るための道具です。書き上がったものをコピーして、 GitHub の編集画面に貼れば設定が変わります。ここでは保存できません （GitHub Pages は静的なページを配るだけで、書き込みを受け付ける先がないため）。

安全装置にあたる項目は、この画面には出していません。 zero_streak_limit や monitoring_hours は実行間隔と対で決まっていて、 単独で動かすと誤通知や誤警告の原因になります。読み込んだ値をそのまま持ち越します。 変える必要があるときは技術資料を読んでから直接編集してください。

1. いまの設定を読み込む

自分のリポジトリの config.json を開いて、中身をすべて貼り付けてください。 初めての方は「ゼロから作る」を押せば、空の状態から始められます。

2. 監視するページ

UR のサイトで条件を絞り込んだ検索結果ページの URL を入れます。 ここに出てくる部屋だけが監視の対象になります。

3. 通知する条件

ここに合う部屋が新しく出たときだけ Slack に通知します。 建物名は部分一致、空欄は「その条件は問わない」の意味です。

4. 一覧で目立たせる物件

空き部屋一覧のページで赤枠にする建物名です。通知の条件とは別で、見た目だけに効きます。

5. すべての新着を通知する

既定はオフです。オンにすると監視URLに出るすべての新着が飛ぶため、通知の数が一気に増えます。

6. 書き出して貼り付ける

GitHub の編集画面を開く

貼り付けるときは、中身をすべて選んで置き換えてください。 一部だけ書き換えると JSON が壊れ、次の実行で読み込めなくなります。
